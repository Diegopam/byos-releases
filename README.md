# byOS Releases

Repositório público de distribuição oficial dos pacotes binários pré-compilados do **byOS** (`by-compositor` + sessão Wayland + utilitários e `.byt` pré-instaláveis).

> O código-fonte permanece em repositório privado; apenas os pacotes assinados/empacotados de lançamento são publicados na aba **Releases**.

## Atualizar via terminal
```bash
byos-update --check
byos-update
```
